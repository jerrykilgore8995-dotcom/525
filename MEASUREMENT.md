# Measurement and acceptance protocol
Use ngspice double precision, calibrated differential RMS voltage: dBu = 20 log10(Vrms/0.775). Explicit digital calibration default -18 dBFS sine peak = +4 dBu; log peak/RMS convention, amplitude and input headroom; use floating-point host tests above nominal full scale as needed. Source impedance nominal 150 ohm differential and additional 50/600 ohm, load 10k (user interface), 600, 2k, 20k, plus actual factory load. Never normalize away makeup or distortion. Define reference nodes and source/load, sample window, GR method, temperature, test duration, FFT/window and uncertainty per result.

## Control coverage
Input and output each 0–100% in 1% angular increments, include endpoints and all physical detents. Independent Cartesian product, not linked sweeps. Ceiling every actual detent (historical 0–20 in 2 dB increments; verify reissue), include actual taper if continuous. Both op-amps; four release states (00=0.1s, 10=0.5s, 01=2s, 11=2.5s); C/L/OFF/BYP; D-S on/off. Test every combination, including apparently inactive controls to establish invariance. matrix.py generates the baseline; use --count for exact count. For continuous controls this is a finite exhaustive grid, not literally every real-valued position; add half-step off-grid holdouts and adaptive finer sampling around knee, extrema or violations. If ceiling continuous, use 1% increments and update generator. All configurations need the core test battery below; equivalent cases may reuse results only after proving circuit-state equivalence and documenting hash mapping. Do not use sampling alone as proof of every setting. Shard by control IDs and stimulus family, checkpoint unique IDs and solver versions. Full matrix is very large; never mark skipped, failed or unmeasured rows as passing. Report counts and coverage.

## Core test battery per configuration
* DC operating point and headroom; gain at low level, below/through/above knee; input -60 to +28 dBu in 1 dB increments, 0.1 dB near knee, clipping point and extremes. Measure steady output, internal attenuation, threshold, knee, local slope and maximum GR. Fit ratio on unclipped settled above-knee region, including 2:1 and 20:1; report slope uncertainty. Measure ceiling gain and threshold separately and combined. Do not force constant output if reference differs.
* AC small signal 5 Hz–200 kHz, at least 48 points/octave; magnitude/phase and group delay; audio spec 20 Hz–40 kHz analog, plugin compare only representable frequencies under Nyquist. AC linearization alone is not compression response: also transient fundamental transfer at multiple operating/GR points and modulated probe under settled compression. Absolute phase and polarity, delay removed only if declared; report raw and compensated. Impulse and step response with GR off and active.
* Sines 20, 30, 50, 100, 200, 500 Hz, 1, 2, 5, 10, 15, 20 and 40 kHz (analog); levels -40/-30/-18/-10/0/+4/+10/+15/+20/+24/+27 dBu, plus actual 0/1/3/6/10/15/20/25 dB GR where reachable. Record fundamental, THD, THD+N separately, K2–K20 in dBc and linear amplitude, phase of harmonics, noise floor, DC and clipping. Use coherent settled windows, sufficient internal sample/FFT bandwidth for K20; never interpret alias as harmonic. Report inaccessible points and why. Analyze low-frequency detector ripple, op-amp contribution and FET distortion by node observation; isolated diagnostic tests must not replace full circuit measurements.
* Dynamics: fixed carrier amplitude steps, bursts and probe/envelope tests at 30/100/1k/5k/10k Hz, 1/3/6/10/15/20/25 dB GR; fast, slow and repeated bursts, varying durations and recovery history, different initial states, release all four settings. Measure time to 10/50/63.2/90% of final GR, 10–90% attack, release to 1 dB remaining, dB/s and entire envelope. Document manufacturer definitions if found. 15 us requires submicrosecond timestep convergence (start <=0.25 us during attack, halve and compare); variable steps and segmented recovery with precision checks. Release frequency/program dependent, do not impose one exponential. Allow at least 5 time constants or measured settling. Include peak overshoot, control ripple, hold effects if present, pumping and recovery after overload.
* D-S: sweep sensitivity relative to same GR, matched broadband and sibilant bursts, detector filter transfer; voice energy curve, low-frequency and broadband behavior. OFF retains coloration; BYP tests unity/no processing, including controls and switching.
* IMD SMPTE 60 Hz/7 kHz 4:1, CCIF 19/20 kHz, multitone and two-tone under varied GR, random broadband, drum, guitar, bass, vocal stimuli from licensed or generated audio. Test noise spectrum, hum only if evidenced (ideal rails), dynamic range, crosstalk/link if applicable; source/load impedance vs frequency, transformer saturation and hysteresis, temperature and component tolerance sensitivity on representative and worst-case nodes, repeat full core tests where changed operating domain invalidates fit.

## Pass rules
Reference vs hardware: compare same revision, rails, load, level, GR, temperature and method. Manufacturer nominal values are not exact measured curves. Historical distortion ceiling 0.5% is not a universal target; obtain actual curves/captures. Record unresolved differences instead of fudging. 990 is alternative, validate independently.
Plugin vs SPICE: <=5% target, 5–10% only enumerated owner-review exceptions, >10% fail. Use relative linear amplitude error for gain and harmonics, ratio and time; for THD use relative error above measurement floor, not percentage-point subtraction. Near zero use calibrated absolute tolerances (proposed -100 dBc harmonic floor, <=0.01 percentage point THD when below reliable floor); publish floor and justify. For FR report absolute dB error additionally (target <=0.25 dB, maximum 0.5 dB), for phase use wrapped angular difference (target <=3 degrees, maximum 5 degrees) rather than dividing by near-zero phase. GR absolute error target <=0.25 dB, max 0.5 dB, plus relative comparison above 5 dB. Dynamic envelope compare maximum and RMS dB error, overshoot and timing, not just one timestamp. Use independent validation data; report max, p95, median, failures and worst configuration per metric. Never hide failures through averaged score. Where physical uncertainty exceeds tolerances report unverified. Store raw data, units, IDs, netlist/model hashes, parameter values, host sample/block size, seed, method and pass reason. Refit and rerun failed cases plus regression suite until accepted or clearly blocked.
