## Mod ratios

Place a **Mod** toggle in the header or footer, beside the amplifier selector. In Compress, clicking the **2:1** ratio label cycles **2:1 → 4:1 → 8:1 → 12:1 → 2:1** when Mod is on. Mod off uses the stock Compress circuit. Clicking the ratio label with Mod off selects Compress using the original button. Limit, OFF and BYP retain their existing mode functions. Disable ratio cycling outside Compress. Retain the selected Mod ratio when the user switches modes or temporarily disables Mod. Save the toggle and selected ratio in plug-in state and expose both to host automation. Existing sessions default to Mod off at 2:1. Keep the stock faceplate geometry.
